## 5. 앱 권한
최종 앱이 요청하는 권한: 인터넷, 알림(Android 13+, 할 일 알림), 진동(체크 시 햅틱), 부팅 후 알림 재등록.
저장소 접근과 '다른 앱 위에 표시' 권한은 `app.json`의 `blockedPermissions`로 제거했습니다. 별도로 신고해야 하는 민감 권한은 없습니다.

## 6. 빌드와 업로드

```bash
cd client
eas build -p android --profile production   # .aab 생성 (버전 코드는 EAS가 자동 증가)
```

1. 첫 업로드는 Play Console에서 직접 합니다: **테스트 → 비공개 테스트 → 새 버전 만들기** → `.aab` 업로드.
   (`eas submit -p android`는 Google 서비스 계정 키를 연결한 뒤, 두 번째 버전부터 쓰면 편합니다.)
2. **Play 앱 서명**이 켜지면 **설정 → 앱 무결성 → 앱 서명 키 인증서**의 SHA-1을 복사해서,
   Google Cloud Console에 패키지 `com.editodo.app`인 Android OAuth 클라이언트를 **하나 더** 만드세요.
   빠뜨리면 스토어에서 받은 앱에서만 Google 로그인이 실패합니다.
3. **개인 개발자 계정**이면(2023년 11월 이후 생성): 프로덕션 출시 전에 **테스터 12명 이상이 14일 동안** 비공개 테스트에 참여해야 합니다.
   조직(사업자) 계정이면 이 조건이 없습니다.
