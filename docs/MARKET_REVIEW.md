# EdiTodo 출시 평가

작성일: 2026-10-22
기준: 현재 코드와 웹 화면(실기기 사용 전). 지금 상태로 앱 마켓에 출시했다고 가정한 평가입니다.

## 총평

**출시 초기 예상 평점: ★3.5 ~ 4.0**

"예쁘고 가벼운 투두 + 한 줄 일기"로는 매력이 있습니다. 하지만 투두 앱의 기본기인 **오프라인 사용, 반복 일정, 홈 화면 위젯**이 빠져 있어서 매일 쓰는 앱으로 남기는 어렵습니다.

## 잘한 점

| 항목 | 내용 |
|---|---|
| 가입 없이 시작 | 바로 쓰다가 로그인하면 기록이 그 계정으로 합쳐집니다. 진입 장벽이 낮습니다. |
| 꾸미기 | 테마 4종, 색상 5종, 글꼴, 다크 모드, 스티커. "취향"을 내세울 수 있는 요소입니다. |
| 할 일 + 하루 기록 | 스티커 캘린더로 한 달을 돌아보는 구성은 감성 쪽 사용자에게 잘 맞습니다. |
| 간편 로그인 | 카카오·구글·애플. 애플 로그인이 있어 iOS 심사 조건(4.8)도 맞습니다. |
| 심사 준비 | 계정 삭제 페이지, 개인정보처리방침, 데이터 보안 답변, 불필요 권한 제거까지 갖췄습니다. |

## 아쉬운 점 (사용자 리뷰에 나올 순서)

### 1. 인터넷이 없으면 못 씀 (가장 치명적)
할 일을 체크할 때도 서버 접속이 필요합니다. 지하철·엘리베이터에서 저장이 안 되면 "느리다", "저장이 안 된다"는 1점 리뷰로 바로 이어집니다.

### 2. 기본 기능 부족
- 반복 일정 없음 (매일 운동, 매주 회의 등)
- 못 한 일이 다음 날로 넘어가지 않음 → 날짜를 바꿔 다시 적어야 함
- 홈 화면 위젯 없음 (투두 앱을 계속 쓰게 만드는 핵심 기능)
- 할 일별 시간 알림, 순서 바꾸기, 검색 없음

### 3. 경쟁 앱
국내에서는 **투두메이트**가 "투두 + 이모지 + 꾸미기"로 이미 자리를 잡았습니다. 스토어 첫 화면에서 "EdiTodo를 써야 하는 이유"가 바로 보여야 합니다. 지금은 "테마를 고르는 투두" 정도로 읽힙니다.

### 4. 완성도 디테일
- 한국어 화면에 영어 문구가 섞여 있음 (`+ new todo`)
- 앱 아이콘이 임시 디자인 (온보딩 캐릭터로 만든 초안)
- 처음 시작할 때 테마 설정 3단계가 있어 바로 쓰고 싶은 사람에게는 조금 김

## 운영 위험 (사용자에게는 안 보이지만 더 위험한 것)

| 위험 | 내용 |
|---|---|
| **DB 백업 없음** | 서버에 문제가 생기면 모든 회원 기록이 사라집니다. 기록 앱에서 데이터 손실은 되돌릴 수 없는 신뢰 손상입니다. |
| 서버 사양 | 무료 1GB 서버 한 대를 dubuck과 함께 씁니다. 사용자가 늘면 느려질 수 있고, 장애 알림(감시)도 없습니다. |
| 수익 모델 없음 | 지금은 비용이 거의 없어 괜찮지만, 프리미엄 테마·광고 제거 등 방향을 정해 둘 필요가 있습니다. |

## 우선순위

| 순위 | 할 일 | 이유 | 시점 |
|---|---|---|---|
| 1 | DB 매일 자동 백업 | 데이터 손실은 되돌릴 수 없음 (약 10분 작업) | 출시 전 |
| 2 | ~~못 한 일 다음 날로 넘기기~~ ✅ 2026-10-22 | 오늘 화면에 '지난 날 못 한 일 N개 · 오늘로 가져오기' (최근 30일) | 완료 |
| 3 | ~~오프라인에서도 보기·체크~~ ✅ 2026-10-22 | 할 일 목록을 기기에 저장, 오프라인 변경은 연결되면 순서대로 전송 (하루 기록은 아직 온라인 전용) | 완료 |
| 4 | ~~반복 일정~~ ✅ 2026-10-22 | 매일 / 평일 / 매주 같은 요일, 삭제 시 '이 날만 / 반복 전체' | 완료 |
| 5 | 홈 화면 위젯 | 매일 다시 열게 만드는 기능 (작업량 큼) | 업데이트 |
| 6 | 영어 문구 정리 ✅ / 정식 아이콘 (남음) | 첫인상. 아이콘은 디자인 필요 | 아이콘만 남음 |

1~2번은 출시 전에 바로 할 수 있고, 3번까지 하면 리뷰 평점이 확실히 달라질 것으로 봅니다.

## 참고
- 실제 휴대폰에서 써 본 결과가 아니라 코드와 웹 화면 기준의 예상입니다. 출시 전 실기기에서 로그인·알림·키보드·다크 모드를 확인해야 합니다.
- 스토어 등록 자료와 제출 절차는 `store/android/README.md`를 참고하세요.
